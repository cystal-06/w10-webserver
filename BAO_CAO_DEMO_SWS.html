I. GIỚI THIỆU SƠ LƯỢC

Chương trình sws (Simple Web Server) được xây dựng hoàn chỉnh bằng ngôn ngữ C phục vụ giao thức HTTP/1.0 (RFC 1945) và kịch bản động CGI/1.1 (RFC 3875). Máy chủ hỗ trợ đầy đủ các cờ tham số dòng lệnh:

sws [-dh] [-c dir] [-i address] [-l file] [-p port] dir

Hệ thống có khả năng chạy nền (System Daemon), lắng nghe đa cổng kép IPv4/IPv6, tự động sinh danh mục thư mục khi thiếu index.html, nhận diện định dạng MIME tự động qua libmagic, chặn đứng tấn công Path Traversal và ghi nhật ký truy cập theo chuẩn Apache Common Log.

II. CÁC LỆNH CHẠY THỬ & KẾT QUẢ THỰC NGHIỆM

1. Biên dịch dự án và kiểm tra hướng dẫn sử dụng (-h)

Câu lệnh:

make clean && make
./sws -h

Mô tả: Biên dịch mã nguồn qua Makefile chuẩn với các cờ nghiêm ngặt (-Wall -Wextra -Werror -pedantic) không phát sinh lỗi cảnh báo. Lệnh ./sws -h hiển thị bảng hướng dẫn sử dụng các tùy chọn.

[DÁN ẢNH CHỤP TERMINAL DEMO 1 TẠI ĐÂY]
Hình 1: Quá trình biên dịch bằng make và kiểm tra câu lệnh trợ giúp ./sws -h

2. Chạy bộ kiểm thử tự động toàn diện (make test)

Câu lệnh:

make test

Mô tả: Kịch bản tự động kiểm tra đồng loạt các tính năng: GET file tĩnh, HEAD header, Directory Indexing, chạy CGI script, chặn Path Traversal và ghi file log Apache. Tất cả đều đạt trạng thái [PASS].

[DÁN ẢNH CHỤP TERMINAL DEMO 2 TẠI ĐÂY]
Hình 2: Kết quả chạy thành công toàn bộ bài test tự động với make test

3. Khởi động Server ở chế độ gỡ lỗi (-d)

Câu lệnh:

./sws -d -p 8080 -c test/cgi-bin -l test/access.log test/www

Mô tả: Máy chủ chạy trực tiếp trên console (foreground), lắng nghe cổng 8080 và in toàn bộ nhật ký truy cập trực tiếp ra màn hình terminal.

[DÁN ẢNH CHỤP TERMINAL DEMO 3 TẠI ĐÂY]
Hình 3: Máy chủ sws đang chạy ở chế độ Debug trên cổng 8080

4. Tải file tĩnh trang chủ (GET /index.html)

Câu lệnh:

curl -i http://localhost:8080/index.html

(Hoặc mở trình duyệt Web truy cập: http://localhost:8080)

Mô tả: Máy chủ phản hồi mã HTTP/1.0 200 OK, tiêu đề Content-Type: text/html do libmagic nhận diện, độ dài Content-Length và nội dung trang web hiển thị đúng thông tin sinh viên Nguyễn Công Đức.

[DÁN ẢNH CHỤP DEMO 4 TẠI ĐÂY]
Hình 4: Tải trang web tĩnh GET /index.html qua curl hoặc trình duyệt

5. Kiểm tra phương thức HEAD (chỉ nhận Header, không có Body)

Câu lệnh:

curl -i -I http://localhost:8080/index.html

Mô tả: Server phản hồi mã 200 OK và các trường tiêu đề đầy đủ, nhưng ngắt luồng không gửi phần thân tệp (Body) theo chuẩn RFC 1945.

[DÁN ẢNH CHỤP TERMINAL DEMO 5 TẠI ĐÂY]
Hình 5: Phản hồi phương thức HEAD chỉ trả về Headers, không kèm nội dung

6. Kiểm tra tự động sinh danh mục thư mục (Directory Indexing)

Câu lệnh:

curl -i http://localhost:8080/docs/

(Hoặc mở trình duyệt truy cập: http://localhost:8080/docs/)

Mô tả: Do thư mục test/www/docs/ không có file index.html, máy chủ tự động sinh ra mã HTML danh sách tập tin theo thứ tự chữ cái và tự động ẩn các tệp có dấu chấm . ở đầu.

[DÁN ẢNH CHỤP DEMO 6 TẠI ĐÂY]
Hình 6: Giao diện Directory Indexing tự động khi truy cập thư mục /docs/

7. Thực thi kịch bản động CGI (/cgi-bin/hello.cgi)

Câu lệnh:

curl -i http://localhost:8080/cgi-bin/hello.cgi

Mô tả: Yêu cầu được chuyển tiếp vào thư mục CGI Root qua cờ -c, máy chủ thiết lập biến môi trường RFC 3875 (như REQUEST_METHOD=GET, REMOTE_ADDR=::1, SERVER_PORT=8080) và trả về kết quả xuất của script.

[DÁN ẢNH CHỤP TERMINAL DEMO 7 TẠI ĐÂY]
Hình 7: Kết quả thực thi script động CGI in các thông số môi trường hệ thống

8. Thử nghiệm tấn công Directory Traversal (chống đọc trộm file)

Câu lệnh:

curl -i http://localhost:8080/../../etc/passwd

Mô tả: Máy chủ sử dụng hàm realpath() đối chiếu ranh giới, phát hiện hành vi truy cập trái phép vượt ngoài Document Root và lập tức chặn đứng với mã lỗi 404 Not Found (hoặc 403 Forbidden).

[DÁN ẢNH CHỤP TERMINAL DEMO 8 TẠI ĐÂY]
Hình 8: Cơ chế bảo mật realpath chặn đứng tấn công Path Traversal

9. Kiểm tra file nhật ký truy cập Apache (access.log)

Câu lệnh:

cat test/access.log

Mô tả: File log ghi nhận đầy đủ các yêu cầu theo định dạng chuẩn Apache biến thể: %a %t "%r" %>s %b (Địa chỉ IP, thời gian GMT ISO 8601, dòng request, mã trạng thái, số byte).

[DÁN ẢNH CHỤP TERMINAL DEMO 9 TẠI ĐÂY]
Hình 9: Nội dung tệp access.log ghi lại lịch sử truy cập chuẩn Apache

10. Kiểm tra chế độ chạy ngầm System Daemon

Câu lệnh:

./sws -p 8080 -c test/cgi-bin -l test/access.log test/www
ps -ef | grep sws

Mô tả: Khi không dùng cờ -d, tiến trình tự tách khỏi terminal, chạy ngầm dưới nền hệ điều hành Linux. Sau đó có thể dừng server bằng lệnh pkill sws.

Hình 10: Máy chủ sws chạy ngầm dưới dạng System Daemon kiểm tra qua ps -ef
