I. TỔNG QUAN HỆ THỐNG & CẤU TRÚC DỰ ÁN

1. Mục tiêu đề tài: Xây dựng hoàn chỉnh một máy chủ web độc lập (Simple Web Server - sws) bằng ngôn ngữ C, tương tác trực tiếp với Socket API của nhân UNIX. Máy chủ tuân thủ nghiêm ngặt chuẩn HTTP/1.0 (RFC 1945), hỗ trợ thực thi kịch bản động CGI/1.1 (RFC 3875), vận hành như một System Daemon chuẩn mực và đạt tính khả chuyển trên cả ba nền tảng: NetBSD 11.0, Linux và OmniOS.

2. Cú pháp dòng lệnh và Bảng tham số:

sws [-dh] [-c dir] [-i address] [-l file] [-p port] dir
Cờ / Tham số Mặc định Chức năng kỹ thuật
dir Bắt buộc Thư mục gốc chứa tài liệu phục vụ web (Document Root).
-p port 8080 Cổng TCP lắng nghe các kết nối HTTP gửi tới.
-i address Mọi địa chỉ Ràng buộc địa chỉ IPv4 hoặc IPv6 cụ thể (mặc định lắng nghe đa giao thức trên cả IPv4 và IPv6).
-c dir Tắt Chỉ định thư mục CGI Root cho phép thực thi kịch bản động với URI bắt đầu bằng /cgi-bin/.
-l file Tắt Ghi nhật ký truy cập vào file chỉ định theo định dạng Apache: %a %t "%r" %>s %b.
-d Tắt (Daemon) Chế độ gỡ lỗi: Chạy trên foreground, phục vụ tuần tự 1 kết nối tại một thời điểm, log ra stdout.
-h Tắt Hiển thị tóm tắt hướng dẫn sử dụng và thoát với mã trạng thái 0.

3. Cấu trúc Mô-đun Hệ thống (Modular Architecture):

w10-webserver/
├── Makefile       : Quy tắc biên dịch nghiêm ngặt (-Wall -Wextra -Werror -pedantic)
├── README         : Thông tin phân công nhiệm vụ nhóm và hướng dẫn vận hành
├── checklist      : Bảng kiểm định chất lượng nộp bài theo chuẩn CS631
├── SPECIFICATION  : Báo cáo đặc tả hệ thống toàn diện (SSD)
├── src/
│   ├── sws.h      : Định nghĩa cấu trúc ServerConfig, HttpRequest, HttpResponse
│   ├── main.c     : CLI parser (getopt), quy trình hóa Daemon, xử lý SIGCHLD
│   ├── network.c  : Quản lý socket kép Dual-Stack (IPv4 & IPv6), poll(), accept()
│   ├── http.c     : Bộ phân tích cú pháp HTTP/1.0 (GET, HEAD), 304 Caching, hạ cấp HTTP/1.1
│   ├── resource.c : Phân giải đường dẫn, chống Path Traversal (realpath), Directory Indexing, libmagic
│   ├── cgi.c      : Động cơ chạy script CGI RFC 3875 qua Pipe I/O Redirection
│   └── logger.c   : Hệ thống ghi nhật ký nguyên tử định dạng chuẩn Apache
└── test/
    ├── www/       : Thư mục chứa tài nguyên web tĩnh (index.html, style.css, docs/)
    └── cgi-bin/   : Thư mục chứa kịch bản CGI thực thi (hello.cgi, env.cgi)

4. Quy trình xử lý yêu cầu (Lifecycle Workflow):

Client kết nối ➔ Socket tiếp nhận qua poll() và accept() ➔ Ở chế độ Daemon, máy chủ fork() một tiến trình Worker độc lập ➔ Đọc và phân tích cú pháp HTTP Request ➔ Kiểm tra an toàn đường dẫn chống Path Traversal qua realpath() ➔ Phân luồng xử lý: Tệp tĩnh (kèm mã MIME từ libmagic), Tự sinh Directory Indexing khi thiếu index.html, hoặc Thực thi kịch bản CGI ➔ Ghi nhật ký truy cập vào file log ➔ Đóng kết nối TCP và tự động thu hồi tiến trình con qua tín hiệu SIGCHLD (Zero Zombie).

Thành viên Tỷ trọng Vai trò chính Phân hệ đảm nhiệm & Nhiệm vụ cụ thể
Nguyễn Công Đức
(Nhóm trưởng - User1)		 40% Lead Systems Architect & Core Daemon Engine - Thiết kế kiến trúc Base, cấu trúc dữ liệu cốt lõi (sws.h).
- Bộ phân tích CLI getopt xử lý đủ 6 cờ: -d, -h, -c, -i, -l, -p và dir.
- Quy trình hóa Daemon (fork, setsid, chuyển hướng /dev/null, umask).
- Động cơ mạng Dual-Stack (IPv4 & IPv6 song song, poll, accept).
- Quản lý tiến trình: Bắt SIGCHLD (Zero Zombie), SIGINT/SIGTERM.
- Viết Makefile chuẩn POSIX, bộ test tự động và quản trị kho Git.
Thành viên 2
(User2)		 30% HTTP Protocol & Parser Specialist - Xây dựng bộ phân tích cú pháp HTTP Request (http.c/.h) theo RFC 1945.
- Xử lý phương thức GET và HEAD, kiểm tra Relative URI (từ chối mã 400).
- Hiện thực cơ chế âm thầm hạ cấp (Quiet downgrade) từ HTTP/1.1 về HTTP/1.0.
- Phân tích tiêu đề điều kiện If-Modified-Since (trả về mã 304 Not Modified).
- Xây dựng bộ phát sinh trang mã lỗi HTML chuẩn (400, 403, 404, 500, 501).
Thành viên 3
(User3)		 30% File System, MIME, CGI & Logging Specialist - Quản lý tài nguyên đĩa (resource.c/.h), chống Path Traversal (realpath).
- Xử lý thư mục người dùng ~user (ánh xạ vào /home/user/sws/).
- Tự động tạo danh mục thư mục (Directory Indexing) bằng scandir + alphasort.
- Nhận diện kiểu MIME tự động qua thư viện libmagic (mẫu magic(5)).
- Động cơ thực thi kịch bản CGI (cgi.c/.h - RFC 3875) qua Pipe I/O.
- Module ghi nhật ký truy cập (logger.c/.h) định dạng chuẩn Apache.

II. CÁC LỆNH CHẠY THỬ & KẾT QUẢ THỰC NGHIỆM

1. Biên dịch dự án và kiểm tra hướng dẫn sử dụng (-h)

Câu lệnh:

make clean && make
./sws -h

Mô tả: Biên dịch mã nguồn qua Makefile chuẩn với các cờ nghiêm ngặt (-Wall -Wextra -Werror -pedantic) không phát sinh lỗi cảnh báo. Lệnh ./sws -h hiển thị bảng hướng dẫn sử dụng các tùy chọn.

Câu lệnh:

make test

Mô tả: Kịch bản tự động kiểm tra đồng loạt các tính năng: GET file tĩnh, HEAD header, Directory Indexing, chạy CGI script, chặn Path Traversal và ghi file log Apache. Tất cả đều đạt trạng thái [PASS].

./sws -d -p 8080 -c test/cgi-bin -l test/access.log test/www

curl -i -I http://localhost:8080/index.html

cat test/access.log
